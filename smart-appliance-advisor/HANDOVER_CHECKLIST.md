### 2. 相依套件更新

**更新頻率：**
- **次要版本**（minor）：每月檢查一次
- **修補版本**（patch）：每週檢查一次
- **主要版本**（major）：謹慎評估後再升級

**更新流程：**
```bash
# 檢查過期套件
npm outdated

# 更新修補版本
npm update

# 測試功能
npm run dev
npm run build
```
