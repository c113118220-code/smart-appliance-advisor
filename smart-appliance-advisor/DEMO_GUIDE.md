# Demo 演示指南

## 🎯 Demo 目標
展示全國電子 Digital City 智慧家電提案系統的完整功能，包含門市顧問使用的 iPad 介面與消費者掃描 QR Code 後的手機介面。

---

## 🚀 Demo 前準備

### 1. 資料庫重置
開啟「開發者選單」（右下角懸浮按鈕）→ 點擊「資料庫管理」→ 執行「完整重置資料庫」

**預期結果**：
- ✅ 15 款 Seed Data 電器
- ✅ 0 筆提案紀錄
- ✅ 乾淨的初始狀態

### 2. 瀏覽器 DevTools 準備
- 打開 Chrome DevTools (F12)
- 開啟 Device Toolbar (Ctrl+Shift+M)
- 預設選擇 iPad (768×1024) 模式

### 3. 測試資料準備（選用）
如果想展示「歷史紀錄」功能，建議先建立 1~2 筆示範提案：
- 情境 A：獨居長輩 + 套房 + 緊急救援需求
- 情境 B：雙薪小家庭 + 兩房一廳 + 節能省電需求

## 📱 Demo 流程（建議 10-15 分鐘）

### 第一部分：智慧提案流程 (5-7 分鐘)

#### Step 1: 問卷填寫
1. 進入首頁「智慧提案」Tab
2. 展示 4 步驟引導式問卷：

**步驟 1 - 族群選擇**
```
情境：雙薪小家庭 → 選擇「雙薪小家庭」
說明：系統會根據族群特性過濾適合的電器
```

**步驟 2 - 格局選擇**
```
情境：兩房一廳 → 選擇「兩房一廳」
說明：系統會根據空間大小推薦合適尺寸的電器
```

**步驟 3 - 生活需求（多選）**
```
情境：節能省電 + 健康空淨 → 勾選這兩項
說明：系統會根據需求標籤計算電器的適配分數
```

**步驟 4 - 電器需求（多選）**
```
情境：節能省電 + 健康空淨 → 勾選這兩項
說明：與步驟 3 搭配，強化特定需求的權重
```

3. 點擊「生成推薦」按鈕

#### Step 2: 查看推薦結果
1. 系統顯示 3 組套餐：
   - 💰 經濟安心版（1 大 + 2 小 + 1 智慧）
   - 🏠 智慧生活版（2 大 + 3 小 + 2 智慧）
   - ⭐ 全屋旗艦版（2 大 + 4 小 + 3 智慧）

2. 展示套餐卡片功能：
   - 點擊「展開電器清單」查看詳細內容
   - 點擊「帶入 3D 空間預覽」（顯示第二階段預留功能）
   - 強調：每組套餐都有推薦理由

3. 選擇一個套餐（建議：智慧生活版）
4. 點擊「下一步：生成 QR Code」

#### Step 3: QR Code 生成
1. 展示 QR Code 頁面功能：
   - 左側：QR Code 與操作按鈕
   - 右側：套餐摘要與顧客條件

2. 示範功能：
   - **「下載 QR Code 圖片」**：儲存為 PNG（實際 Demo 可跳過）
   - **「複製提案連結」**：複製到剪貼簿
   - **「模擬消費者手機畫面」**：🌟 重點功能

3. 點擊「模擬消費者手機畫面」按鈕

#### Step 4: 消費者手機介面
1. 新視窗開啟 (375×812) 顯示手機版提案單
2. 展示消費者看到的內容：
   - 全國電子品牌 Header（洋紅色 #E6007E）
   - 套餐總價與分期月付
   - 電器清單（按類別分組：大型/小型/智慧）
   - 每件電器的詳細資訊（名稱、品牌、價格、特色）
   - 底部「前往門市洽詢」CTA 按鈕

3. 強調重點：
   - 消費者可在手機上隨時查看提案
   - 方便回家後與家人討論
   - 提案編號可追蹤

---

### 第二部分：商品管理功能 (2-3 分鐘)

1. 切換到「商品管理」Tab
2. 展示電器列表（15 款 Seed Data）

#### 功能示範：

**搜尋與篩選**
```
- 搜尋「Dyson」→ 顯示 Dyson 商品
- 篩選「大型家電」→ 顯示 5 件大型家電
- 價格範圍 10000~30000 → 過濾價格
- 點擊「清除篩選」→ 恢復全部
```

**新增電器（快速示範）**
```
1. 點擊「新增商品」
2. 填寫必填欄位：
   - 名稱：Demo 測試洗衣機
   - 品牌：Samsung
   - 類別：大型家電
   - 價格：25000
   - 尺寸：60 × 60 × 85
3. 勾選適用族群與格局
4. 點擊「新增商品」
5. 表格出現新電器
```

**編輯電器**
```
1. 點擊任一電器的「編輯」按鈕
2. 修改價格（例如降價 1000）
3. 點擊「儲存變更」
4. 價格更新成功
```

**刪除電器**
```
1. 點擊剛新增的測試電器「刪除」按鈕
2. 確認刪除
3. 電器從列表消失
```

---

### 第三部分：歷史紀錄查詢 (2-3 分鐘)

1. 切換到「歷史紀錄」Tab
2. 展示提案卡片（如果有測試資料）

#### 功能示範：

**查看詳情**
```
1. 點擊任一提案的「查看詳情」
2. Modal 顯示完整資訊：
   - 套餐資訊（總價、月付、電器數量）
   - 顧客條件（族群、格局、需求標籤）
   - 完整電器清單
   - 時間資訊
3. 點擊「複製提案連結」（可重新分享給顧客）
4. 關閉 Modal
```

**篩選功能**
```
- 選擇族群：雙薪小家庭
- 選擇格局：兩房一廳
- 設定日期範圍：今天 ~ 今天
- 點擊「搜尋」
- 點擊「清除篩選」
```

**刪除提案**
```
1. 點擊「刪除」按鈕
2. 確認刪除
3. 提案從列表消失
```

## 🐛 常見問題與處理

### Q1: QR Code 掃描失敗？
**A**: 使用「模擬消費者手機畫面」按鈕代替，效果完全相同。

### Q2: 推薦套餐看起來重複？
**A**: 這是因為 Seed Data 只有 15 款電器，實際使用會有更多商品可選。

### Q3: 資料亂掉怎麼辦？
**A**: 開啟「開發者選單」→「資料庫管理」→「完整重置資料庫」

### Q4: 想展示不同情境的推薦？
**A**: 重新走一次問卷，選擇不同的族群與格局組合。

### Q5: 手機版底部導覽被遮住？
**A**: 這是正常的，手機版使用固定底部導覽，主要內容會保留底部間距。
