# 推薦演算法設計文件

## 概述

智慧家電推薦系統採用**階層式過濾 + 權重評分 + 品類平衡**的演算法設計，確保推薦結果既符合顧客實際需求，又能提供多樣化的家電組合。

---

## 演算法流程

```
顧客選擇（4 步驟問卷）
    ↓
【第一層：硬性過濾】
根據格局與族群過濾不適合的電器
    ↓
【第二層：權重評分】
計算每個電器的需求匹配分數
    ↓
【第三層：品類平衡組合】
確保每組套餐都包含三大類別電器
    ↓
生成 3 組套餐（經濟、智慧、旗艦）
```

---

## 第一層：硬性過濾

### 目的
排除明顯不適合的電器，減少後續計算量並避免不合理推薦。

### 過濾規則

#### 1. 格局適配度檢查
```typescript
// 檢查電器是否適用於選定格局
if (!appliance.suitableFor.layouts.includes(layout)) {
  return false; // 排除
}
```

**範例**：
- 套房格局：排除 Panasonic 650L 冰箱（88×73×183 cm，過大）
- 透天厝格局：接受所有尺寸電器

#### 2. 族群適配度檢查
```typescript
// 檢查電器是否適用於選定族群
if (!appliance.suitableFor.demographics.includes(demographic)) {
  return false; // 排除
}
```

**範例**：
- 獨居長輩：優先推薦操作簡單、安全性高的電器
- 三代同堂：推薦大容量、多功能電器

#### 3. 特殊格局規則
```typescript
// 套房格局：排除過大電器
if (layout === 'studio') {
  if (appliance.widthCm > 60 || appliance.depthCm > 60) {
    return false; // 排除
  }
}
```

### 過濾結果
經過第一層過濾後，電器數量通常會從 15 款減少到 8-12 款。

## 第二層：權重評分

### 目的
根據顧客的「核心生活需求」與「核心電器需求」，計算每個電器的匹配度分數。

### 標籤權重對應表

| 顧客需求 | 電器標籤 | 說明 |
|---------|---------|------|
| 智慧監控 | smartMonitoring | 智慧攝影機、電子鎖等 |
| 生活輔助 | lifeAssistance | 掃地機器人、氣炸鍋等 |
| 緊急救援 | emergencyRescue | 跌倒偵測器、警報器等 |
| 防呆安全 | foolproofSafety | 操作簡單、安全性高的電器 |
| 節能省電 | energySaving | 一級能效、變頻技術等 |
| 健康空淨 | healthyAir | 空氣清淨機、除濕機等 |

### 計分公式

```typescript
score = Σ (電器標籤分數)
```

每個標籤分數範圍：0-10 分

**範例計算**：

顧客選擇：智慧監控、健康空淨

**電器 A（Dyson TP07 空氣清淨機）**：
```
smartMonitoring: 7 分
healthyAir: 10 分
-----------------
總分：17 分
```

**電器 B（LG 滾筒洗衣機）**：
```
smartMonitoring: 5 分
healthyAir: 4 分
-----------------
總分：9 分
```

結果：電器 A 的匹配度高於電器 B

## 第三層：品類平衡組合

### 目的
確保每個套餐都包含**大型家電、健康/生活小家電、智慧監控/安全裝置**三大類別，提供完整的居家解決方案。

### 電器類別定義

| 類別 | 代碼 | 說明 | 範例 |
|-----|------|------|------|
| 大型家電 | large | 冰箱、洗衣機 | Panasonic 冰箱、LG 洗衣機 |
| 健康/生活小家電 | small | 空氣清淨機、掃地機器人、除濕機、氣炸鍋等 | Dyson 空氣清淨機、石頭掃地機器人 |
| 智慧監控/安全裝置 | smart | 智慧門鎖、攝影機、感應器 | Yale 電子鎖、小米攝影機 |

### 套餐配置

| 套餐名稱 | 大型家電 | 小家電 | 智慧裝置 | 總數量 | 目標價格 |
|---------|---------|--------|---------|--------|---------|
| 💰 經濟安心版 | 1 | 2 | 1 | 4 | 2-3 萬元 |
| 🏠 智慧生活版 | 2 | 3 | 2 | 7 | 5-6 萬元 |
| ⭐ 全屋旗艦版 | 2 | 4 | 3 | 9 | 8-10 萬元 |

### 組合邏輯

```typescript
// 1. 按類別分組並依分數排序
const largeAppliances = filteredAppliances
  .filter(a => a.category === 'large')
  .sort((a, b) => b.score - a.score);

const smallAppliances = filteredAppliances
  .filter(a => a.category === 'small')
  .sort((a, b) => b.score - a.score);

const smartAppliances = filteredAppliances
  .filter(a => a.category === 'smart')
  .sort((a, b) => b.score - a.score);

// 2. 從每個類別取最高分的 N 件電器
const economyPackage = [
  ...largeAppliances.slice(0, 1),  // 取前 1 件大型家電
  ...smallAppliances.slice(0, 2),  // 取前 2 件小家電
  ...smartAppliances.slice(0, 1),  // 取前 1 件智慧裝置
];
```

## 演算法特性

### 優點
1. **精準過濾**：硬性過濾避免不合理推薦
2. **彈性評分**：權重計分適應不同需求組合
3. **品類平衡**：確保套餐完整性
4. **價格梯度**：三組套餐提供不同價格選擇

### 可擴充性
1. **新增電器**：只需設定標籤權重與適用條件
2. **調整套餐配置**：修改 `PACKAGE_CONFIGS` 常數
3. **自訂過濾規則**：在第一層新增特殊邏輯
4. **優化評分公式**：可引入加權係數或非線性計算

## 未來優化方向

1. **機器學習整合**：
   - 收集顧客選擇偏好
   - 訓練個性化推薦模型
   - A/B Testing 驗證效果

2. **協同過濾**：
   - 「購買此套餐的顧客也購買了...」
   - 基於相似族群的推薦

3. **動態調整**：
   - 根據季節調整推薦（夏季加強空調、除濕機）
   - 根據庫存調整優先順序

4. **多目標優化**：
   - 同時考慮價格、空間利用率、能源效率
   - Pareto 最優解
